## 🌟 Template Overview
**Kalyanam Gold** is an interactive, mobile-responsive South Indian & Traditional Royal Indian digital wedding invitation featuring rich animations, sound, and elegant aesthetics.

### ✨ Key Features:
1. **Interactive Temple Entrance**:
   - South Indian Gopuram silhouette, ambient glowing diyas.
   - Interactive golden "Open Invitation" curtain / envelope reveal animation.
2. **Background Music Track**:
   - Autoplay on entrance with persistent floating music toggle (sound wave visualizer & mute controls).
3. **Hero & Live Countdown**:
   - Real-time countdown timer to the wedding ceremony.
   - Ornamental filigree & couple names.
4. **Traditional Illustrated Couple Section**:
   - Sacred bridal & groom traditional portraits with temple bells and marigold garlands.
5. **Ceremony & Reception Event Cards**:
   - Timings, dates, and direct Google Maps navigation buttons.
6. **3D Photo Gallery Carousel**:
   - 7 curated photographs with stack animation, counter (01/07), and full-screen lightbox modal.
7. **Custom Footer Branding**:
   - Dedicated bottom bar featuring **A.C.P Invites (7000371321)** with direct tap-to-call dialer.

## 🚀 How to Run Locally

### Option 1: One-Click (Windows)
Double-click on [`start.bat`](start.bat).

### Option 2: Node.js (Terminal)
```bash
npm start
# or
node server.js
```
Open your browser at: **http://localhost:8080**

### Option 3: Python (Alternative)
```bash
python -m http.server 8080
```

## 📁 Folder Structure
- `index.html` — Main HTML entry point & font links
- `assets/` — CSS stylesheets, compiled JavaScript bundle, backgrounds, and floral artwork
- `photogallery/` — High-resolution gallery images (`pi1.png` - `pi7.png`)
- `music.mp3` — Wedding theme background music
- `server.js` — High-performance Node.js static server with HTTP range seeking for audio
- `start.bat` — Windows one-click start script
- `package.json` — Project configuration & start scripts
